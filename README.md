# AlphaRegionPriority

Плагин Paper и WorldGuard для автоматической настройки регионов.

- Обычные регионы получают priority 1.
- __global__ исключается из изменений.
- Флаги применяются к существующим регионам при запуске.
- Новые регионы обнаруживаются периодической проверкой.
- Команда управления: /arp reload.

GitHub Actions собирает JAR автоматически при push в main. Готовый JAR находится в Artifacts запуска workflow.

Важно: перед установкой сделайте резервную копию папки WorldGuard. Конфигурация перезаписывает указанные флаги у обычных регионов.
